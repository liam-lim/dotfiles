# macOS settings checklist

Ideas come from [mathiasbynens/dotfiles](https://github.com/mathiasbynens/dotfiles) (`.macos`), used as a menu, not run as a script.
Each item names a setting. The value is decided when we do it.

Loop for one item: change it in the Tart VM, `snap`, keep the real key, save to chezmoi, tick.

`[ ]` open · `[x]` saved to chezmoi · ~~struck~~ skipped · `(sudo)` system level
